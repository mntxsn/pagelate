                  LibreTranslate

                  Open-source, privacy-friendly text (not page) translation. Point it at your own self-hosted server or a public instance — see the list of mirrors at LibreTranslate mirrors. Some instances require an API key. Once added, LibreTranslate appears as an option in the text-translation popup.

                  DeepL Free API

                  Configure a DeepL Free API key to translate text (not pages). The result is shown directly in the popup — no extra tab is opened. Get a free key (500k characters/month) at deepl.com/pro-api. Once a key is added, DeepL appears as an option in the text-translation popup.

                  Google proxy

                  If you live in a country with a firewall that blocks the Google translation service and have a server to act as a proxy, you can configure it here.

                  Note: this is not a regular http/https/socks proxy. It is a server created or shared with you. Translation requests will be sent to this server, which must know how to direct them to Google's servers.
